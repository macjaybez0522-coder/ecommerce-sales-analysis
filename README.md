# 📊 E-commerce Sales Analysis

## 📌 Project Overview
This project analyzes e-commerce transaction data to extract business insights using Python.

## 🛠️ Tools Used
- Python (Pandas, NumPy)
- Excel
- Git & GitHub

## 📊 Key Analysis
- Data Cleaning & Preprocessing
- Revenue Analysis
- Country-wise Sales
- Customer Segmentation (RFM)

## 📈 Key Insights
- Identified top revenue-generating countries
- Found high-value customers using RFM analysis
- Cleaned and processed 500K+ records

Online Retail Dataset
